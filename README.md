# Asteroids

Jocul Asteroids în browser, realizat cu SVG și JavaScript.

## Funcționalități

- nava se deplasează pe ecran și trage cu rachete
- asteroizii au un număr aleator de „vieți”, afișat pe ei; viteza și rezistența lor cresc cu nivelul
- scor, vieți (3 la început) și niveluri (un nivel nou la fiecare 1000 de puncte)
- clasament al scorurilor maxime, păstrat în `localStorage`

## Controale

| Tastă | Acțiune |
|---|---|
| Săgeți | deplasarea navei |
| `z` / `c` | rotire la stânga / la dreapta |
| `x` | foc |

## Rulare

Se deschide `index.html` în browser.
